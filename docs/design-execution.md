# 唐宋诗词｜设计执行文档 v1.0

日期：2026-10-08。执行依据：已确认的视觉说明 v0.3、功能需求 v1.0、用户提供的《唐宋诗词精选300首.md》。此次用户授权依据规范搭建网站。本文件先于应用实现编写，不修改已确认视觉文档。新增旅程和诗集界面采用同一视觉系统，作为首版可运行评审稿；后续视觉调整仍遵守先看图、确认后改视觉 MD。

## 1. 必须守住的视觉

使用已确认的无文字纯背景，暗蓝水墨柔缓层山、柳枝、小树、月光与留白保持完整。场景文字由真实 HTML 叠加；宋体、暖白诗句、浅灰蓝正文。严禁银河群山、密集粒子、科技地球、白色纸底。背景是静态合成图，光晕呼吸与少量独立星点另加；不能声称已经有独立山柳模型或真正可拆解三维场景。

首屏直接开始选字，诗句桌面约在上半区中央，候选沿缺字上下排列；手机保持一分句完整可读。进度放在左下，旅程、诗集及设置为小型文字入口。成功后展示整个联句、篇名、今译和共鸣，正文不闪烁。诗集和旅程作为全屏阅读层，背景适当压暗，采用细线、间距和文字层次，不增加白底卡片。

## 2. 知识库映射与核对

源文件共有 300 个编号，001—300。使用编号作为稳定 ID，不以标题当 ID，因为词牌与同名诗会重复。原文、作者、朝代、篇名、今译、共鸣和标签保持来源文本；不自动改写用户共鸣、不自动生成史料解释。

每首一个核心题。诗眼在名句中时，取包含该字的一个分句为选字文本，成功阅读显示完整名句；诗眼不在名句但在原文中时，取原文包含该字的分句出题，成功阅读展示包含该字的完整原文行，名句另在详情保留，避免挖空不存在的字。

核对发现 25 首属于上述名句/诗眼不一致情况（不等于原文错误）。原始诗眼“直、圆”按单字题规则先取“直”，其拟字只取“直”对应候选。“桂枝香·金陵怀古”编号 189 的诗眼“冷”在原文与名句均不存在：应用适配层暂改为“凝”，取“但寒烟衰草凝绿”出题，候选沿用提供拟字加正确字；此为明确的适配修正，仍可由用户改成其他字。原附件不修改，内容核对记录保留源值与适配值。

另有 9 首的诗眼或拟字为词组，不符合单字选择要求；适配层已将其转为单字题（编号 011、061、202、221、222、226、232、255、279），适配值与候选写入 content-adaptations.json，可供用户复核。其中 226 改取同名句中的“愁”，其余尽量取原诗眼中的单字；原词组仍在详情保留。

正确字与四个拟字组成五项选择，按编号插入稳定位置，不默认位于中心。初始中心为空位，候选必须经操作才进入中心。若字在句内多次出现，按定位后的第一个目标位置挖空；不替换整句所有同字。

原文全文按源文件行段保存。阅读联句按逗号/句号适当分行，不能只剩出题的一个分句；《泊船瓜洲》必须完整呈现“春风又绿江南岸，明月何时照我还。”。网站不额外编造知识库未提供的炼字说明；今译标为意境今译，共鸣标为此刻的你，提供的诗眼可在详情用短元数据呈现。

## 3. 页面与功能执行

| 视图 | 实现要求 |
| --- | --- |
| 选字 | 句内无框滚轮；指针、触摸、滚轮、上下键、点击相邻字；停稳后判定；错误温和提示 |
| 阅读 | 完整联句发光；显示作者、篇名、今译、共鸣；收藏、全文、下一首；答案预览不算完成 |
| 旅程 | 按源顺序 30 卷×10 首；每卷 n/10、全库 n/300；自由进入；已完成可重读/再做 |
| 诗集 | 全部、已点亮、收藏、待点亮；搜索标题作者正文；唐宋与体裁筛选；保留筛选及滚动 |
| 详情 | 全文、完整名句、诗眼、今译、共鸣、标签；收藏；独立选字；范围内上一首/下一首 |
| 卷末 | 待点亮与全卷完成区分；不无限循环跳过作品；下一未完成卷；300 首完成可重读 |
| 设置 | 减少动态；本机保存提示；导出、校验后合并/替换导入、清除确认、保存失败重试 |

提示仅在源库提供 hint 时显示，此库未提供，不生成虚假提示。原文查看和收藏不自动点亮，只有自主选字正确才计完成。收集按不同 ID 计，重复作答不增加；取消收藏不倒扣点亮。

从诗集进入独立练习时保留主旅程状态和列表位置，结束可返回。普通阅读空白轻触进下一首，菜单、文字选择、滚动与收藏不得误触。

## 4. 状态与本机保存

按此前规范采用本机保存：完成映射、收藏最近操作（含取消状态）、会话与动效偏好。独立键保存每首完成与收藏，避免两个标签页以整个旧集合覆盖新集合。完成时间首次不覆盖，练习时间可更新；计数由集合派生。存储异常不显示永久保存成功，保留当前状态并提供重试/导出。

导出含格式版本、合集 ID、300 首记录映射及会话。导入限定 JSON 大小并校验类型、ID、时间和状态；默认完成并集、收藏按最近操作合并，默认不覆盖本机当前会话。替换和清除需明确确认，无效输入不部分写入。数据存储在当前浏览器，换设备不会自动同步。

## 5. 工程与资产

采用静态网页应用：HTML、CSS、ES Modules、JSON 内容，多个可返回的哈希视图。无外部 AI 调用、无强制账户，无服务器用户数据库；本机保存属于当前规范明确范围。字体优先本机宋体与可用中文衬线回退，不让外部字体网络阻塞启动。

项目保存源附件副本、内容转换脚本、适配核对记录、结构化 JSON、背景与应用源文件。网页默认私有发布；公开分享不自动开启。背景使用本次已生成素材，不重新设计。桌面全景；手机以保证中心文字及底部山景为优先调整背景定位，受限于横版资产，尚无独立竖版背景。

## 6. 动效与可访问性

诗句正确后的外围光晕 6 秒一次轻呼吸，字形核心稳定；星点随机错相，3—8 秒温和闪烁。减少动态与系统偏好都能关闭持续效果。文字保持足够对比度，正文不低于 16px；操作可键盘完成，滚轮仅在控件范围处理；反馈为可读文本且辅助技术可宣布。

## 7. 检查与完成标准

1. 300 条编号连续唯一；全文、作者、今译、共鸣非空；所有题目单字有效且候选含正确字一次；30 卷不重叠。
2. 自主答对、答案预览、重做、跳过、卷末、全集完成统计准确；刷新恢复阅读。
3. 诗集搜索、组合筛选、收藏切换、详情与返回位置可用；独立练习不覆盖旅程。
4. 备份导入校验、重复合并不重复计数；存储异常可恢复。
5. 页面引用文件存在、脚本语法通过；自动化 DOM 交互覆盖核心流程及移动布局检查。可用的浏览器预览能力受环境限制，实际未做的视觉 QA 如实注明。
6. 保存设计执行文档，完成网站发布并返回可访问链接。用户可在实际首版上审阅新增旅程与诗集界面，反馈后再更新视觉规范。
