# 唐宋诗词｜优化版交互设计 v1.1

日期：2026-10-08。顺序：先编写本文，再实施、检查和更新既有网站。依据：已确认的暗蓝水墨视觉、功能规范 v1.0、用户当前截图与优化要求。本轮背景、原文库、进度口径不更换；优先修正文字层次、滚轮手感、成功反馈及声音。

## 1. 字段与内容层次

| 旧称 | 新显示名称 |
| --- | --- |
| 意境 / 意境今译 | 诗意今译 |
| 此刻的你 | 此刻共鸣 |

“此刻共鸣”模块顺序固定为：模块名称 → 标签内容单独一行 → 共鸣正文。

示例：

> 此刻共鸣
>
> 送别 · 友情 · 豁达
>
> 好友这个东西，不按距离结算，按秒回结算。

标签来自每首作品原有 tags，保留原始次序，不显示“标签”字样，不作为浮动徽章插到正文旁。标签字号约 14px，正文 16—17px，两者颜色与间距区分。选中阅读页、答案预览、重读与全文详情采用同样称呼与结构，详情底部不重复展示一份标签。

这是显示名称调整，原 meaning、realLife、tags 数据字段及备份结构兼容，不需要重置用户记录。

## 2. 当前问题与实施目标

旧版每跨过一段拖动距离才直接替换字符，手指运动与字符运动脱节；滚轮有较强步进节流，缺少连续滚动和吸附过渡。成功后整块页面直接重绘，持续光晕缺少有层次的一次性反馈。当前没有滑动和确认声音。

新目标：手指拖动时字跟着移动；松手后以有限惯性与轻微阻尼落位；先落位再判定；成功时通过一个可中断的时间线连接“答案点亮—第一次柔闪—第二次整句回应—释意出现”。声音与动作同步，安静、短促、有余韵。

## 3. 技术选择与边界

当前插件目录未找到对应 GSAP MCP，目录搜索结果不代表全互联网不存在此服务。本轮不接入不相关视频或设计插件。MCP 不是网页播放动画的运行引擎；本轮使用 requestAnimationFrame 控制滚轮位移、浏览器 Web Animations 控制时间线、Web Audio 合成声音。

无需外部运行时 CDN、音效下载或付费账号。外晕、变换与透明度为主；正文不做持续模糊或闪烁。原静态背景维持，动效层只添加局部光与少量非具象星点。

技术参考：
- https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API
- https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices

## 4. 选字：真正连续的纵向滚轮

把空位与五个候选字放在同一个有限字轨上；初始空位独立于任何正确候选。每帧按连续 position 值布置字符，不通过频繁重建 DOM 替换字。中间字为最大、最清晰；相邻字沿竖向移动并轻微旋转缩小，远处字渐隐；诗句其他字始终稳定在同一基线。

| 阶段 | 动作与参数起点 |
| --- | --- |
| 手指按下 | 取消正在执行的吸附与判定，当前位置不跳回整数 |
| 拖动 | 1:1 跟随纵向距离；位移连续；使用 transform，不移动整句 |
| 候选经过中心 | 中心邻近状态轻量更新；触发一次柔和刻度音，限频约 55ms |
| 松手 | 根据末段速度投射目标，最多额外移动约 1 个字位；停止后吸附最近候选 |
| 吸附 | 约 260—340ms，缓出、极小回弹，不来回震荡 |
| 判定 | 吸附完成后稳定 350—450ms；途经正确字不判定 |
| 输入边界 | 有限字轨，超界小幅阻尼，松手回边界；不高速循环 |

点击相邻候选字和上下键使用同一吸附引擎，约 220—280ms，不能直接换字。滚轮输入连续累积，约 120ms 没有新事件后吸附；不全局拦截滚轮。中间字点击依次移动到下一候选，到最后一字停住，不突然跳回起点。

拖动阈值约 5—7px 后才捕获指针，保留正常点击。松手不产生另一次误点击；pointercancel/失去指针时停止惯性，不判定成功。页面切换、菜单打开、题目重置应销毁控制器与动画，旧题回调不能污染新题。

## 5. 正确后的双闪灵动反馈

“双闪”是两次柔和光脉冲，不是全屏快速曝光。只给诗句和少量局部星芒发光，暗色背景和阅读文字保持稳定。

| 判定后时刻 | 视觉 | 声音 |
| --- | --- | --- |
| 0—260ms | 保留当前答案字，光核增强；邻字预览渐隐，整行字轻微抬起不超过 3px | 第一枚短亮音 |
| 260—620ms | 显示完整联句，第一道柔光沿答案所在行展开，局部星芒轻散 | 余音衰减 |
| 620—1000ms | 稍弱的第二次光脉冲回应到两行诗句，6—10 枚微星点短程飘散后消失 | 第二枚较轻高音 |
| 850—1500ms | 篇名、诗意今译、标签与共鸣逐组淡入，位移最多 8px | 无额外提示音 |
| 1500ms 之后 | 转入原有 6 秒柔光呼吸，开放下一首 | 安静 |

答案字与整句保持宋体，不挤成立体金属字。成功才触发双闪，答案预览/重读/刷新恢复不重复播放完整成功音画。成功的点亮记录先保存，不等待动画播完。动画期间下一首按钮暂时不可用，阻止误切；页面导航仍可立即中断。

错误字停留可读，并做一次很小的落位回应，显示“再斟酌一字”，不红闪、不惩罚性蜂鸣、不震屏。

## 6. 下一首过渡

正常下一首采用约 170ms 淡出当前文字，再淡入新题约 320ms，背景保持。切题期间锁定重复下一首输入。跳过也用此过渡，但不播放成功声音、不改变完成数。少量自动状态更新不能整块重放入场动画。

## 7. 声音设计

默认音效开启；第一次用户真实点击、触摸或按键后才创建/恢复音频上下文。页面首次加载或刷新不自动发声。若浏览器阻止播放，用户可以继续完整流程。

| 音效 | 设计 |
| --- | --- |
| 滑动刻度 | 约 35—55ms，轻木音/软拨弦；每跨一字轻响，限制连发频率 |
| 正确确认 | 两枚间隔约 620ms 的轻铃音，第二枚更轻更高；约 1 秒内自然衰减 |
| 错误选择 | 无惩罚音 |

用振荡器与增益包络合成，起落平滑，避免爆音。播放量总体低，设置页提供音效开关、音量滑块和“试听确认音”；主导航提供简洁的“音效 / 静音”开关。静音立即停止当前声音，关页/切后台停止未完成声音序列，不在返回时补播。选择关闭动效不自动关闭声音，两者独立。

声音设置保存为独立偏好，兼容旧记录；可纳入导出/导入备份但不改变完成与收藏内容。声音不可作为正确反馈的唯一渠道。

## 8. 减少动态与性能

系统或设置开启减少动态时：关闭旋转、惯性回弹、双闪与飞散星点；选择器保持直接可读的位移/短吸附，正确只用约 180ms 淡入与静态光晕。持续星闪和呼吸仍关闭。

字符每帧只修改少量 transform/opacity；旧动画可取消、同一元素不堆叠动画；不对整个场景反复应用大范围模糊。后台不持续绘制，无外部网络依赖。

## 9. 验收与记录

1. 阅读/详情称呼统一为“诗意今译”“此刻共鸣”；每首的标签位于共鸣正文前，单独一行，且不重复。
2. 选字拖动连续跟随；松手吸附稳定；越界能回到有效位置；点击、键盘和滚轮共享结果。
3. 快速经过正确字无成功，停稳后才判定；新题不会收到旧题的成功回调。
4. 成功时确有两次有节奏的局部光脉冲；完整联句与正文正确；错误、预览与刷新不错误播放奖励。
5. 滑动刻度与确认音可用，静音即时生效、音量可调整；初始页面不自动播放。
6. 减少动态保留完整功能，旧完成、收藏、备份兼容。
7. 运行内容与记录回归检查，增加滚轮控制器、取消回调、动效时间线和音频调度检查。当前静态项目环境不具备受支持的真实浏览器预览，动态手感和扬声器听感最终仍需用户打开网站核验；模拟测试不宣称为浏览器音画验收。

本文件定义本轮执行方案；按用户“先写文档再执行”的授权继续实现。不修改先前确认的水墨背景构图，不重新生成静态风格图。
